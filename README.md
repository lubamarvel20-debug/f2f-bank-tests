# F2F Bank Tests

Автотесты для тестового задания по приложению F2F Bank.
Тесты покрывают основные сценарии работы с сервисом переводов ДС между пользователями: регистрацию, авторизацию, пополнение баланса, перевод дс, а также негативные проверки.

## Запуск приложения

Для работы необходим **Docker** и **Docker Compose**. 
Адрес приложения: http://localhost/ 

1. Клонируйте репозиторий:
   bash
   git clone https://github.com/lubamarvel20-debug/f2f-bank-tests.git
   cd f2f-bank-tests

2. Запуск контейнеров и остановка:
 bash
 docker compose up -d

 bash
 docker compose down

## Запуск тестов. Потребуется Node.js (версия 18+) и Playwright
1. Установите зависимости:
 npm install

2. Установите браузеры Playwright
 npx playwright install  

3. Запустите тесты:
 npx playwright test 

 Запуск конкретного теста: 
 npx playwright test <имя_файла>.spec.ts 

4. Просмотр отчета:
 npx playwright show-report

Что было использовано:
 Playwright - end-2-end тесты
 TypeScript - язык написания тестов
 Docker - контейнеризация приложения
 Node.js - среда выполнения

Все тесты независимые, можно запускать как по одному, так и все вместе :)

## Тест-кейсы


Всего реализовано 11 автотестов, покрывающих позитивные, негативные и граничные сценарии.

| № | Название теста | Что тестируется | Входные данные | Ожидаемый результат | Приоритет |
|---|----------------|-----------------|----------------|----------------------|-------------|
| 1 | Открытие главной страницы | Проверка доступности сайта и загрузки главной страницы | Открытие `http://localhost/` | Страница загружается (любой заголовок) | **Низкий** |
| 2 | Авторизация с валидными данными | Вход в систему с правильным email и паролем | Email: `testuser@example.com`, пароль: `qwerty123` | Редирект на главную страницу, пользователь авторизован | **Критический** |
| 3 | Авторизация с неверным паролем | Попытка входа с правильным email, но неверным паролем | Email: `testuser@example.com`, пароль: `qwerty1` (неверный) | Ошибка «Login failed», вход не выполнен |**Высокий** |
| 4 | Регистрация с уже существующим email | Попытка регистрации с email, который уже зарегистрирован | Имя: `Иван`, фамилия: `Иванов`, email: `testuser@example.com` (уже существует), пароль: `qwerty777` | Ошибка «User with this email already exists», регистрация не выполнена | **Высокий** |
| 5 | Пополнение баланса | Успешное пополнение баланса на сумму 500 | Авторизованный пользователь, сумма пополнения: `500` | Баланс увеличивается (текст заголовка `Balance:` меняется после возврата на главную - вообще, меняется сразу же на /transaction, но никак не получалось это в коде описать, поэтому добавла переход на main) | **Критический** |
| 6 | Регистрация нового пользователя | Успешная регистрация с уникальным email и паролем | Имя: `Иван`, фамилия: `Петров`, email: уникальный (`test+<timestamp>@example.com`), пароль: `qwerty123` | Сообщение «Registration successful! Please log in.», пользователь создан | **Критический** |
| 7 | Перевод суммы, превышающей баланс | Попытка перевода суммы больше текущего баланса | Номер получателя: `+79819067661`, сумма: `5000` (> баланса), назначение: `dinner money` | Ошибка «Transfer failed. Check your balance.», баланс не меняется | **Высокий** |
| 8 | Перевод отрицательной суммы | Попытка перевода с отрицательным значением | Номер получателя: `+79819067661`, сумма: `-10`, назначение: `for the chips` | Ошибка «Amount must be greater than zero», перевод не выполнен | **Высокий** |
| 9 | Перевод без указания номера телефона | Попытка перевода с пустым полем «Phone number» | Сумма: `10`, назначение: `chips`, номер телефона пуст | Ошибка «Phone number is required», перевод не выполнен | **Высокий** |
| 10 | Успешный перевод денег | Перевод средств другому пользователю | Номер получателя: `+79819067661`, сумма: `500`, назначение: `lunch money` | Перевод выполнен успешно (проверяется визуально или по сообщению об успехе) | **Критический** |
| 11 | Проверка валидации номера телефона | Ввод некорректного номера (меньше 10 цифр) | Номер: `+7981906` (короткий), сумма: `15`, назначение: `chips` | Ошибка «Phone must contain 10–15 digits», перевод не выполнен | **Средний** |
